## 실패 사유

- GitHub Actions 사전수집(`fetch-security-news.yml`)이 아직 오늘자 실행을 완료하지 못한 상태입니다.
- 이 클라우드 루틴의 폴백 수집(WebFetch, `security-news-collector`)도 시도했으나 두 출처 모두 `EGRESS_BLOCKED`로 실패했습니다.
  - 보안뉴스: `EGRESS_BLOCKED: Access to www.boannews.com is blocked by the network egress proxy.`
  - KISA 보호나라: `EGRESS_BLOCKED: Access to www.boho.or.kr is blocked by the network egress proxy.`

두 경로 모두 실패한 상태이므로, 데이터를 지어내지 않고 이 안내문만 작성합니다.

GitHub Actions 사전수집이 늦게라도 성공해 저장소에 실제 데이터가 커밋되면, 그 push 이벤트가 webhook을 통해 이 클라우드 루틴을 다시 트리거해 실제 데이터로 이 다이제스트를 덮어쓰고 정정 이메일을 재발송합니다 (과거 09-21 사례와 동일한 패턴).
